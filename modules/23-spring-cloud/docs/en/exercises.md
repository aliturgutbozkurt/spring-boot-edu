# How to Work

1. The starter code is in `modules/23-spring-cloud/exercise/`. Find the `TODO` comments.
2. Every exercise already has tests, and they stay **red** until you solve it.
3. Run the tests:

```bash
./mvnw -Pexercises -pl modules/23-spring-cloud/exercise test
```

4. The exercise is done when all tests are green.
5. If you get stuck, read the hints first, then the solution in `modules/23-spring-cloud/solution/`.

> [!TIP]
> To run the tests of a single exercise: `-Dtest=Exercise1Test`
